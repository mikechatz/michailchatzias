ASSETS FOLDER GUIDE
===================

Drop your media files in this folder:

1. background.jpg
   - This will appear as the atmospheric background image behind the semi-transparent dark tint.
   - Any moody, stage, instrument, or landscape photo works beautifully.

2. portrait.jpg
   - Your main artist portrait in the "About" section.

3. gallery/
   - Create a subfolder called "gallery" and drop your photos there:
     - photo1.jpg
     - photo2.jpg
     - photo3.jpg
     - photo4.jpg

If any file is not yet added, the website automatically displays clean, minimalist placeholders so nothing ever looks broken.
